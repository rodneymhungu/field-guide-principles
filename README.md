# field-guide-principles

The rules I build single-page technical guides by, and the reasoning behind them. Read [PRINCIPLES.md](PRINCIPLES.md).

Every guide I publish links back to this repository from its README and its footer. The philosophy lives here. The guides apply it. When a rule changes, it changes here first and the guides follow.

Guides built on these principles are listed at the end of PRINCIPLES.md.
